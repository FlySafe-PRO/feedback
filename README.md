## English

### Feature requests and bug reports

Open the FlySafe feedback repository on GitHub, sign in, search existing issues, then choose New issue and a template. For bugs, include steps to reproduce, expected and actual results, app version, device and OS/browser. For features, explain the problem and your proposed solution. Issues are public; remove personal data before posting.

You can write in any language. Choose Bug report, Feature request or Translation correction. Submit one topic per issue, add screenshots if helpful, and follow replies on GitHub.

[Open FlySafe feedback](https://github.com/FlySafe-PRO/feedback/issues/new/choose) · [GitHub Issues](https://github.com/FlySafe-PRO/feedback/issues)

## Slovenščina

### Predlogi funkcij in prijave napak

Odprite repozitorij FlySafe feedback na GitHubu, se prijavite, poiščite obstoječe prijave ter izberite New issue in predlogo. Pri napakah navedite korake za ponovitev, pričakovani in dejanski rezultat, različico aplikacije, napravo in OS/brskalnik. Pri predlogih opišite težavo in predlagano rešitev. Prijave so javne; pred objavo odstranite osebne podatke.

Pišete lahko v katerem koli jeziku. Izberite Bug report (prijava napake), Feature request (predlog funkcije) ali Translation correction (popravek prevoda). Za vsako temo odprite ločeno prijavo, po potrebi dodajte posnetke zaslona in spremljajte odgovore na GitHubu.

[Odpri FlySafe feedback](https://github.com/FlySafe-PRO/feedback/issues/new/choose) · [GitHub Issues](https://github.com/FlySafe-PRO/feedback/issues)

## Italiano

### Richieste di funzionalità e segnalazioni di bug

Apri il repository FlySafe feedback su GitHub, accedi, cerca le segnalazioni esistenti, poi scegli New issue e un modello. Per i bug, indica i passaggi per riprodurli, i risultati attesi ed effettivi, la versione dell’app, il dispositivo e il sistema operativo/browser. Per le funzionalità, spiega il problema e la soluzione proposta. Le segnalazioni sono pubbliche; rimuovi i dati personali prima di pubblicare.

Puoi scrivere in qualsiasi lingua. Scegli Bug report (segnalazione di bug), Feature request (richiesta di funzionalità) o Translation correction (correzione della traduzione). Apri una segnalazione per argomento, aggiungi schermate se utili e segui le risposte su GitHub.

## Français

### Demandes de fonctionnalités et signalements de bugs

Ouvrez le dépôt FlySafe feedback sur GitHub, connectez-vous, recherchez les tickets existants, puis choisissez New issue et un modèle. Pour un bug, indiquez les étapes de reproduction, les résultats attendus et obtenus, la version de l’application, l’appareil et le système/navigateur. Pour une fonctionnalité, expliquez le problème et la solution proposée. Les tickets sont publics ; retirez les données personnelles avant de publier.

Vous pouvez écrire dans la langue de votre choix. Choisissez Bug report (signalement de bug), Feature request (demande de fonctionnalité) ou Translation correction (correction de traduction). Créez un ticket par sujet, ajoutez des captures d’écran si nécessaire et suivez les réponses sur GitHub.

## Čeština

### Návrhy funkcí a hlášení chyb

Otevřete repozitář FlySafe feedback na GitHubu, přihlaste se, prohledejte existující hlášení a vyberte New issue a šablonu. U chyb uveďte kroky k reprodukci, očekávaný a skutečný výsledek, verzi aplikace, zařízení a OS/prohlížeč. U funkcí popište problém a navrhované řešení. Hlášení jsou veřejná; před zveřejněním odstraňte osobní údaje.

Můžete psát v kterémkoli jazyce. Vyberte Bug report (hlášení chyby), Feature request (návrh funkce) nebo Translation correction (oprava překladu). Pro každé téma vytvořte samostatné hlášení, případně přidejte snímky obrazovky a sledujte odpovědi na GitHubu.

Abra o repositório FlySafe feedback no GitHub, inicie sessão, pesquise os relatos existentes e escolha New issue e um modelo. ## Magyar

### Funkciójavaslatok és hibajelentések

Nyisd meg a FlySafe feedback GitHub-tárolót, jelentkezz be, keress a meglévő bejelentések között, majd válaszd a New issue lehetőséget és egy sablont. Hibánál add meg a reprodukálás lépéseit, a várt és tényleges eredményt, az alkalmazás verzióját, az eszközt és az operációs rendszert/böngészőt. Funkciójavaslatnál írd le a problémát és a javasolt megoldást. A bejelentések nyilvánosak; közzététel előtt távolítsd el a személyes adatokat.

Bármely nyelven írhatsz. Válaszd a Bug report (hibajelentés), Feature request (funkciójavaslat) vagy Translation correction (fordításjavítás) sablont. Témánként külön bejelentést nyiss, szükség esetén adj hozzá képernyőképeket, és kövesd a válaszokat a GitHubon.
